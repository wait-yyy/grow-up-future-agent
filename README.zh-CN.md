# DCRDCI — 有记忆的 AI 伙伴

> 一个真正记得你的 AI 聊天伙伴。每次对话后自动提炼为结构化记忆文档，按文件夹归类，并在后续聊天时作为上下文（Main_link）注入——让 AI 随着时间真正了解你。

[English Docs](./README.md)

---

## 功能特性

- **带记忆的 AI 对话** — 每次对话后自动提炼为紧凑的主题小文档
- **Main_link 上下文注入** — 勾选文件夹 → 该文件夹下的文档被合并为一段上下文 → 作为系统提示注入每次新对话
- **基于文件夹的文档归类** — 文档可归属多个文件夹；文件夹作为可选的记忆作用域
- **文档生命周期** — `pending` → `kept` / `discarded`；随时预览、编辑、重新生成
- **语音输入** — 集成 Web Speech API，静音自动停止
- **Token 用量仪表盘** — 热力图、日/月统计、按类型分组
- **成长轨迹** — 按时间线展示所有记忆，含统计（陪伴天数、记忆总数、主题数）
- **完全本地化** — 所有数据通过 Dexie 存储在浏览器 IndexedDB 中，无需后端

## 数据模型

### Session（会话）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `string` | 唯一 ID |
| `title` | `string` | 由首条消息或 AI 自动生成 |
| `selectedFolderIds` | `string[]` | 勾选的文件夹，其下文档构成 Main_link 上下文 |
| `mainLinkContent` | `string` | 由勾选文件夹的文档合并而成的上下文字符串 |
| `createdAt` / `updatedAt` | `number` | 时间戳 |

### Message（消息）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `string` | 唯一 ID |
| `sessionId` | `string` | 所属会话 |
| `role` | `'user' \| 'assistant'` | 发送者 |
| `content` | `string` | 消息文本 |
| `createdAt` | `number` | 时间戳 |

### Document（文档/记忆）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `string` | 唯一 ID |
| `sessionId` | `string` | 来源会话 |
| `folderIds` | `string[]` | 所属文件夹（多对多） |
| `theme` | `string` | 短主题标签（2–4 字） |
| `title` | `string` | 文档标题 |
| `content` | `string` | 精简正文 |
| `status` | `'pending' \| 'kept' \| 'discarded'` | 生命周期状态 |
| `createdAt` | `number` | 时间戳 |

### Folder（文件夹）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `string` | 唯一 ID |
| `name` | `string` | 显示名称 |
| `icon` | `string` | Emoji 图标 |
| `description` | `string` | 文件夹描述 |
| `createdAt` | `number` | 时间戳 |

### Settings（设置）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `apiKey` | `string` | `''` | 用户提供的 API Key（未填则使用内置 Key） |
| `baseUrl` | `string` | `https://api.deepseek.com/v1` | API 地址 |
| `model` | `string` | `deepseek-chat` | 模型名称 |
| `generateTimeout` | `number` | `60000` | 请求超时（毫秒） |

## 核心工作流

```
用户发送消息
       │
       ▼
  addMessage('user')
       │
       ▼
  sendMessage() ─── 以 Main_link 作为系统上下文，流式输出 AI 回复
       │
       ▼
  addMessage('assistant')
       │
       ▼
  autoGenerateDocs() ─── AI 将对话拆分为多个主题小文档
       │                        │
       │                        ▼
       │                 文档保存到 IndexedDB
       │                 归属到当前会话选中的文件夹
       │
       ▼
  （用户切换文件夹勾选）
       │
       ▼
  generateMainLink() ─── AI 将勾选文件夹的所有文档合并为一段上下文
       │                        │
       │                        ▼
       │                 session.mainLinkContent 更新
       │                 （下次对话时注入为新上下文）
       │
       ▼
  下一条消息使用更新后的 Main_link
```

## AI 服务接口

所有 AI 调用在 `src/services/ai.service.ts` 中：

| 函数 | 用途 | Temperature |
|------|------|-------------|
| `sendMessage(messages, mainLink, onDelta)` | 流式对话，Main_link 作为系统提示注入 | 默认 |
| `generateMainLink(docs)` | 将多份文档合并为一段连贯的上下文块 | 0.3 |
| `generateSummaryDocs(messages)` | 将对话拆分为紧凑的主题小文档（JSON 数组） | 0.5 |
| `generateTitle(docs)` | 根据文档主题生成 ≤10 字的会话标题 | 0.3 |

错误处理将 HTTP 状态码映射为用户友好的提示（401→Key 无效，404→模型不存在，429→请求过频，5xx→服务器错误）。

## 数据库迁移

Dexie schema 当前为第 4 版。迁移历史：

| 版本 | 变更 |
|------|------|
| v1 | 初始：sessions, messages, documents, roles |
| v2 | 用 `folders` 替换 `roles`；文档和会话新增 `folderId` |
| v3 | `emotion` 重命名为 `theme`；会话新增 `selectedFolderIds`、`mainLinkContent` |
| v4 | `folderId`（单值）→ `folderIds`（数组，多对多关系） |

## 配置

在应用中点击 ⚙ 设置按钮进行配置：

- **API Key** — 你的 DeepSeek（或 OpenAI 兼容）API Key，未填写时使用内置 Key
- **Base URL** — API 端点（默认：`https://api.deepseek.com/v1`）
- **Model** — 模型名称（默认：`deepseek-chat`）
- **Timeout** — 请求超时毫秒数（默认：60000）

设置持久化在 `localStorage` 中，键名为 `dcrdci-settings`。
